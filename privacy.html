プライバシーポリシー

最終更新日: 2026年11月24日

Oshi-Cal（以下「本サービス」）は、アイドルグループのライブ・イベント予定を集約して表示する、個人運営の非公式ファンツールです。本ポリシーでは、本サービスが扱う情報について説明します。

1. アカウントと同期データ

Googleアカウントでログインすると、お気に入り・メモ・参戦記録などの利用データが、本人のデータを本人の端末間で同期する目的で Google Firestore に保存されます。保存されるのは本サービス上で入力・操作したデータのみで、他の目的には使用しません。

2. Googleカレンダー連携（任意機能）

「おすすめライブ」の精度を上げるための任意機能として、Googleカレンダーとの連携を用意しています。この連携で本サービスが取得するのは、Google Calendar API の freebusy 機能が返す「予定で埋まっている時間帯」の情報だけです。

  • 予定のタイトル・場所・参加者などの内容は一切取得しません。
  • 取得した時間帯の情報は、利用中の端末の中（ブラウザの保存領域）でのみ処理・保存され、本サービスのサーバーや第三者へ送信されることはありません。
  • 連携はいつでもアプリ内のボタンから解除でき、解除すると端末内の情報は削除されます。

3. アクセス解析

本サービスでは、利用状況の把握のために Google Analytics を使用しています。Google Analytics は Cookie 等を用いて匿名の利用統計を収集します。個人を特定する目的では使用しません。

4. プッシュ通知

通知を許可した場合、新着ライブや予定の変更をお知らせするために、端末の通知用トークンを Firebase Cloud Messaging 経由で保存します。通知はアプリ内設定でいつでもオフにできます。

5. 第三者への提供

取得した情報を、法令に基づく場合を除いて第三者に販売・提供することはありません。
