Beer CSS バージョン比較テスト

Oshi-Calの土台（Beer CSS）を、いま固定している 3.9.7 から、最終の3系 3.13.3 へ上げる価値とリスクを、実機で見比べるためのテストページです。2つのページは中身が完全に同じで、読み込むBeer CSSの版だけが違います。各ページの上のボタンでダークモードにも切り替えられます。

① Beer CSS 3.9.7 版（現在の本番と同じ）まずこちらで「いつもの見た目」を確認 ② Beer CSS 3.13.3 版（上げる候補）同じ部品がどう変わるか＋3.13だけの新部品の節があります

判定チェックリスト

  • 日付・時刻の入力欄が普通に見えるか（透明になっていないか）
  • 下部ナビのピル、カードの角丸、チップの大きさが版で変わっていないか
  • ダークモードで光って見える所が無いか
  • ボタンを押した時の縮み方・動きが変わっていないか
  • 3.13だけの節：ボタングループ／ツールバーが部品として使えそうか

3.13だけの節について（項目11）

3.13.3版のページの最後にだけ、3.11で追加された Expressive 標準部品の試し置きがあります（ボタングループ、ツールバー、スプリットボタン、FABメニュー）。3.9.7版には入れていません。この「有る／無い」自体が版の差の確認対象です。

部品のクラス名の確認元：ボタングループ／スプリットボタン／FABメニューは Beer CSS v3.13.3 の公式ドキュメント（docs/BUTTON.md）で確認。ツールバーはドキュメントに作例が無かったため、3.13.3の実CSSのセレクタ（nav.toolbar > a、.active）に基づいて作成しました。アイコンは本番に合わせて Font Awesome を使用しています（公式作例のMaterialアイコン文字からの置き換え）。4部品とも「未確認」のものはありません。

3.13.3版のレイアウト対策について（2026-11-29追記）

3.13.3には「直下に <main> がある親を3列グリッド化する」規則が新しく入っており、そのままでは画面全体が横に崩れます（実機確認で発見）。3.13.3版のページには、この規則を打ち消す対策CSSを入れてあります。本番も同じ作り（body直下にmain）なので、本番に上げる場合も同じ対策が必須です。

見方のコツ

2つのページをブラウザのタブで開き、行き来して同じ部品を見比べてください。セグメントバーと下部ナビは、タップで選択が切り替わりピルが滑ります。
